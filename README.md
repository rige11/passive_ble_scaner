# Пассивный BLE-сканер на базе ESP32-C3 с автоматическим логированием

### Прошивка (ESP32-C3)
*   **Режим работы:** **Passive Scan (`setActiveScan(false)`)**. Радиомодуль контроллера работает исключительно на прием (Listen). Устройство полностью невидимо в эфире.
*   **Ограничение по времени:** Использован программный таймер на базе `millis()`. Ровно через 10 минут (600 000 мс) сканирование аппаратно останавливается.
*   **Оптимизация памяти:** После каждой итерации вызывается метод `pBLEScan->clearResults()`. Это предотвращает переполнение оперативной памяти (Out of Memory) из-за лавинного накопления уникальных пакетов.
*   **Фильтрация данных:** Внедрен программный фильтр дубликатов для исключения мгновенного повторного вывода пакетов от одного и того же девайса.

### Скрипт захвата (Python)
*   **Авто-обнаружение:** Скрипт автоматически сканирует COM-порты системы и находит плату по её уникальным заводским идентификаторам (Vendor ID: `303A`, Product ID: `1001`), исключая необходимость ручного ввода.
*   **Авто-сброс (Auto-Reset):** При подключении скрипт программно дергает линии DTR/RTS, автоматически перезагружая плату. Отсчет 10 минут начинается строго в секунду запуска скрипта на ПК.

## 📋 Формат вывода данных (UART, 115200 baud)

Лог выводится в структурированном виде:
`ADDR: [MAC] | TYPE: [0-3] | RSSI: [dBm] | PAYLOAD: [HEX-строка]`

*   **ADDR:** MAC-адрес устройства.
*   **TYPE:** Тип адреса по спецификации BLE (`0` — Public, `1` — Random для защиты от отслеживания).
*   **RSSI:** Уровень принимаемого сигнала в дБм.
*   **PAYLOAD:** Сырые байты данных пакета в формате EIR (Advertising Data Structure), разбитые по блокам `[Длина] [Тип] [Данные]`.

### Пример реального лога:
=== Автоматический регистратор BLE-логов ===
[УСПЕХ] Обнаружена плата на порту: COM5
Логи будут сохранены в файл: 'esp32_ble_log.txt'

[SYSTEM] Starting 10-minute passive BLE scan...
ADDR: e0:66:85:79:d6:3d | TYPE: 1 | RSSI: -75 dBm | PAYLOAD: 1A FF 4C 00 12 02 EE 03 07 11 06 A3 76 ...
ADDR: 4a:22:d3:bc:01:fe | TYPE: 1 | RSSI: -82 dBm | PAYLOAD: 02 01 06 1A FF 4C 00 02 15 ...
...
[SYSTEM] 10 minutes elapsed. Stopping scan...
[SYSTEM] Scan finished. Idle mode.
```

## 🚀 Инструкция по развертыванию и запуску

### 1. Подготовка и прошивка платы
1. Установите в Arduino IDE поддержку плат ESP32 (версия ядра 3.x).
2. Откройте скетч для esp32
3. В меню `Tools` установите параметр **USB CDC On Boot ➡️ Enabled**
4. Подключите плату к ПК и загрузите прошивку. **Закройте Монитор порта в Arduino IDE**, чтобы освободить COM-порт для Python.

### 2. Запуск логирования на ПК
1. Установите необходимую библиотеку для работы с последовательным портом:

   pip install pyserial

2. Перейдите в папку со скриптом на python и запустите автоматический логгер:

   python log_ble.py

3. Скрипт сам перезагрузит плату, начнет выводить данные на экран и сохранит их в файл `esp32_ble_log.txt` в текущей директории.
